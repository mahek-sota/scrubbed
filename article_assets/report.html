Local de-identification benchmark

Can a local LLM scrub patient identifiers from clinical notes?

Regex, Microsoft Presidio and a 7B model running in Ollama were each asked to find names, dates, addresses and eight other identifier types in synthetic clinical notes. Nothing left the laptop.

01 · SUMMARY

The short answer

Presidio and the local LLM remove about the same share of identifiers (79% and 80%), but they miss different things, and the LLM is about 258× slower. Regex is a precise but narrow baseline.

  • ✓Fast: 19.2 ms per note
  • ✕Misses most hospitals (15%) and ZIP codes (27%)

Local LLM
79F1 score
removes 80% of identifiers · 5.0 s per note
  • ✓Best at hospitals (82%) and addresses (100%)
  • ✓More ages over 89 found (69% vs 41% for Presidio), but often on younger ages too
  • ✕Misses short name mentions (names 68%)
  • ✕About 258× slower than Presidio, and varies run to run

Most of the LLM's misses can be fixed in code. It lists “Alexander, Tracy” once and the code never redacts a later “Ms. Alexander”. Redacting each word of every name it returns lifts name recall from 68% to 88%, with no new false alarms on medical terms.

Let the model point at identifiers; let code remove them. Asking the LLM to rewrite the note instead removed only about 61% of identifiers, and it added, reworded and capitalized text along the way.

The LLM doesn't give the same answer twice. Across three runs on the same note, only 8% of notes came out identical, so a single test run tells you little about the next one.

06 · SIDE EFFECTS

What else gets changed

Every method removes some text that isn't an identifier, like “daily”, a dose or an age. Methods that mark spans only ever delete; asking the LLM to rewrite the note also inserts and rewords text, and leaks more identifiers.

08 · METHOD

How this was measured

Setup

  • 200 synthetic notes from 6 templates (discharge summaries, ED notes, phone messages…), with every identifier's position recorded as it was inserted.
  • 11 identifier types from the HIPAA Safe Harbor list, plus names that are ordinary words (Hope, Will, Rose), lowercase names, and medical terms that contain a name.
  • Regex: hand-written patterns. Presidio: default settings plus a record-number recognizer. Local LLM: qwen2.5:7b-instruct in Ollama, returning identifier text that code then locates and removes.
  • An identifier counts as removed if any of it was redacted (“any overlap”); the exact-boundary score is in the details.
  • Everything ran on one laptop. No note text was sent to an external service.

Limitations

  • Template notes are much cleaner than real ones; every method will do worse on real data.
  • The regex was written by the same author as the templates, so its scores are a best case.
  • One local model at 4-bit; bigger models or other prompts will differ.
  • English and US formats only. Small types (ages over 89, SSNs) have few examples.
  • The rewrite's score is approximate and probably generous.
  • Covers 11 of 18 Safe Harbor identifier types. This is a benchmark, not a compliance tool.
Synthetic data only. A benchmark, not a compliance tool; nothing here claims HIPAA compliance. Generated by python -m deid.report.
